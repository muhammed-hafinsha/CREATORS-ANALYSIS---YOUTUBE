# CREATORS-ANALYSIS---YOUTUBE

## Overview
This project explores the Global YouTube Statistics dataset, containing information on 995 YouTube creators and 28 attributes. It analyzes channel popularity, subscriber growth, video views, category distribution, and estimated earnings.

## Objectives
- Identify leading YouTube channels by subscriber count.
- Explore subscriber and video-view distributions.
- Compare creator categories and country representation.
- Analyze recent views and reported subscriber gains.
- Investigate relationships between channel metrics.
- Examine differences in estimated earnings across categories.

## Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Data preprocessing and missing-value handling
- Outlier analysis
- Feature engineering using channel metrics
- Univariate and bivariate analysis
- Category and country distribution analysis
- Subscriber-versus-view comparisons
- Earnings distribution analysis
- Spearman correlation analysis and heatmaps

## Key Insights
- Entertainment and Music are highly represented categories in the dataset.
- The United States has the largest country representation, followed by India.
- T-Series ranks first by subscribers in the analyzed dataset.
- Subscriber counts and total video views show a moderate positive association.
- Recent views and reported subscriber gains show a strong positive association.
- Estimated earnings vary considerably across categories.
